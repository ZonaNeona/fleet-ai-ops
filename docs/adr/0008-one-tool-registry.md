# 0008. Один реестр инструментов для всех исполнителей

**Статус:** принято

## Контекст

К данным таксопарка обращаются несколько исполнителей:
- встроенный агент в кабинете и консоли;
- свободный текст в Telegram-боте;
- внешние ассистенты через MCP (Claude Desktop, Cursor).

Если у каждого свой набор инструментов, права и описания расходятся.

## Решение

- **Один реестр.** Инструменты описаны один раз в `app/agent.py`: `SCHEMAS` (pydantic-модели аргументов), `DESCRIPTIONS`, `tools_for(role)`.
- **Генерация из реестра.** Схемы для function calling модели и для MCP `tools/list` (`app/mcp.py`) генерируются из него.
- **Права проверяет `execute`.** Роль, видимость объектов и валидация аргументов — до выполнения, одинаково для всех исполнителей.
- **Запись только через черновики.** Инструменты записи (`create_ticket`, `crm_task`) создают черновик. Его подтверждает человек командой домена.

## Последствия

- Новый инструмент сразу доступен агенту, боту и MCP-клиентам. Тест `tests/test_mcp.py` проверяет, что списки совпадают.
- Внешний ассистент не может сделать больше, чем роль в кабинете.

# 0010. Приложение Битрикс24 на PHP + Vue рядом с Python-учётом

**Статус:** принято

## Контекст

Заказчики с Битрикс24 ждут не только чтения данных, но и приложения внутри портала:
- вкладку в карточке сделки;
- робота для бизнес-процессов;
- обработчик событий;
- запись обратно в CRM.

Такие приложения в экосистеме Битрикс24 чаще всего пишут на PHP, а интерфейс встройки — на Vue. Учёт таксопарка при этом остаётся на Python.

## Решение

- **`b24app/` — отдельное локальное приложение Битрикс24.**
  - PHP 8.3 без фреймворка и Composer. `src/`:
    - `Bitrix24` — REST по `client_endpoint` и `access_token`, которые портал передаёт приложению;
    - `Fleet` — клиент API учёта;
    - `Robot` — логика робота «Проверить водителя»;
    - `Tokens` — проверка `application_token`.
  - Точки входа в `public/`: `index.php` (встройка `CRM_DEAL_DETAIL_TAB`), `robot.php`, `event.php`, `install.php`, `api.php` (бэкенд виджета).
  - Vue 3 + TypeScript (`widget/`): вкладка «Водитель» — долг, «оплачено в CRM» против учёта, штрафы, документы, кнопка «Поставить задачу менеджеру».
- **Учёт играет обе роли, нужные приложению:**
  - отдаёт данные о водителе (`/api/b24app/deal/{id}`);
  - отдаёт эмулированный портал по HTTP в формате входящего вебхука (`/api/b24/rest/<ключ>/<метод>.json`).
  - Приложение работает с эмулятором тем же кодом, что и с настоящим порталом.
- **Робот.** Кнопка в кабинете отправляет `robot.php` ту же форму, что портал: `event_token`, `document_id`, `properties`, `auth[…]`. Приложение проверяет `application_token` и пишет в сделку:
  - комментарий в ленту;
  - задачу менеджеру, если есть замечания;
  - ответ робота `bizproc.event.send`.
- **Запись в живой портал** разрешена только при `BITRIX24_WRITE=1` в учёте. В эмулятор — всегда, с журналом вызовов.
- **На сервере** отдельный пул PHP-FPM `ondemand` под пользователем стенда: пока приложение никто не вызывает, PHP-процессов в памяти нет.

## Последствия

- PHP и Vue показаны там, где они органичны, а не ради стека. Учёт остаётся одним кодом на Python.
- Тесты PHP-части идут без сети (`b24app/tests/run.php`): порядок вызовов робота, отказ поддельному `application_token` без единой записи, валидация.
- **Проверено на эмуляторе, не на живом портале.** Установка в настоящий Битрикс24 (`install.php`) написана по документации и требует портала.

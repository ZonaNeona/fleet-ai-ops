# 0003. Суточный потолок расходов на модели

**Статус:** принято

## Контекст

Стенд открыт всем. Без ограничений один скрипт может потратить бюджет на модели за минуты.

## Решение

1. **Резерв.** Перед вызовом под `pg_advisory_xact_lock` проверяется суточный потолок (`DAILY_BUDGET`, по умолчанию $0,50 по МСК) и бронируется верхняя оценка стоимости.
2. **Списание.** После ответа бронь заменяется реальной стоимостью, которую вернул провайдер.
3. **Лимит посетителя.** 10 ИИ-заданий в час на пространство.
4. **Без подмены.** При недоступности модели показывается ошибка, заготовленный ответ не подставляется.

Учёт расходов (`Usage`) переживает удаление пространства.

## Последствия

- Потолок соблюдается и при параллельных запросах.
- Стоимость каждого вызова видна в трассе «Под капотом».

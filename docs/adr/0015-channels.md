# 0015. Каналы: почта, таблицы, робот, VK и MAX, локальная модель — у каждого эмулятор и живой режим

**Статус:** принято

## Контекст

Документы и события приходят в таксопарк не только через Telegram:
- счета от СТО — письмами;
- штрафы — с портала, у которого нет API для парка;
- часть водителей сидит в VK и MAX;
- собственник хочет видеть цифры в своей таблице.

Документы с персональными данными (права, паспорта) нельзя отправлять во внешнюю модель без договора.

## Решение

У каждого канала есть живой режим по ключам и режим без ключей — показ на стенде не зависит от чужих аккаунтов.

- **Почта** (`app/mail.py`):
  - письмо (`.eml` или IMAP-ящик) → вложения PDF и фото становятся входящими документами того же графа LangGraph;
  - письмо без вложений само становится документом;
  - отправитель и тема остаются на документе;
  - IMAP: воркер раз в пять минут читает непрочитанное, а plus-адрес (`docs+<метка>@…`) определяет демопространство.
- **Таблицы** (`app/sheets.py`):
  - утренняя сводка, «сделать сейчас» и реестр документов выгружаются в XLSX всегда, а в Google Sheets — по
    сервисному аккаунту;
  - JWT подписывается локально (`google-auth`), вызовов Sheets API три: добавить листы, очистить, записать;
  - стенд остаётся источником данных, из таблицы ничего не читается.
- **Робот** (`app/robot.py` + учебный портал `app/gov.py`):
  - Playwright в отдельном процессе вставляет госномера, листает страницы;
  - пауза 0,4 с между страницами; 503 и 429 — повтор с нарастающей паузой; снимок каждого шага;
  - сверка с тем, что привёз n8n: сходится / другая сумма / только на портале / только в учёте;
  - новое можно загрузить в учёт теми же записями, что пишет n8n, — водитель увидит штраф в Mini App;
  - капча портала — заглушка с тестовым атрибутом, как на тестовых контурах. Настоящую капчу робот не решает: там
    нужен человек или договорной API.
- **VK и MAX** (`app/channels.py`):
  - одно ядро бота: событие канала приводится к виду апдейта Telegram, ответ ядра — к вызову API канала
    (`messages.send`, `POST /messages`), кнопки — к клавиатурам канала;
  - вебхуки с секретом и дедупликацией, обработка — в воркере;
  - без токенов эмулятор бота показывает, что получил бы каждый канал.
- **Локальная модель для ПДн:**
  - провайдер `ollama` (OpenAI-совместимый API) и правило `PII_LOCAL=1`: документы распознаёт только
    локальная модель;
  - если она недоступна, документ ждёт человека — в облако не уходит;
  - в compose — профиль `local-llm`. На демосервере 4 ГБ модель не запускается: там включён облачный режим, и это
    видно в «Эксплуатации».

## Последствия

- Playwright с Chromium ставится отдельно (`requirements-robot.txt`) и в образ API не входит. Браузер живёт
  только на время запуска; одновременно работает один запуск на сервер.
- Идентичность в VK и MAX своя (`vk:<id>`, `max:<id>`): уведомления и утренняя сводка уходят только в Telegram.
